发布文章

填表后点「发布」会直接推到 GitHub（littlewonderland/fendashi-forest），触发 Pages 重建，10-30 秒后线上就有新文章。
⚠ 这个页面只在你的本机存在，不要把它推到 GitHub repo。

使用流程
1. 填好标题（Slug 会自动从标题生成，可改）
2. 正文直接写 HTML，或先用别的工具转好贴进来
3. Token：粘贴 GitHub PAT（需要 Contents: R/W + Administration: R/W），勾「记住」会存到 localStorage
4. 点「发布」→ 推 GitHub → 触发 Pages → 显示线上链接

提示：点「预览」可以在下方看到文章渲染效果（不推送）。
